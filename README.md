ViralFlowAI Edge TTS

Microserviço de geração de voz para o ViralFlowAI utilizando Edge TTS.

Recursos

- Conversão de texto para fala (TTS)
- Vozes neurais em português brasileiro
- Integração com n8n
- Deploy no Railway

Vozes suportadas

- pt-BR-AntonioNeural
- pt-BR-FranciscaNeural

Uso

Recebe texto via API e retorna áudio MP3 gerado automaticamente.
